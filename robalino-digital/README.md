# Robalino Digital

Static website with a restaurant demo and online store demo. The architecture studio demo is pending the company logo and name.

## Deploy using GitHub and Vercel

1. Create a GitHub repository named `robalino-digital`.
2. Upload the **contents** of this project folder: `dist/`, `vercel.json`, and this README. Do not upload the ZIP itself.
3. In Vercel choose **Add New → Project**, then import this GitHub repository.
4. Use Framework Preset **Other**, Root Directory **./**, no Build Command, and Output Directory **dist**. The supplied `vercel.json` sets the static-site configuration.
5. Deploy. Future commits to the connected production branch trigger updated deployments.

## Customer website-builder prototype

Open `/create.html`. Customers enter business details, choose a package/style, optionally upload a logo, and generate an isolated preview. They can download a self-contained HTML draft and prepare a WhatsApp review request. The downloaded draft must be attached manually.

This version uses templates, not a live AI API. It does not publish customer sites, accept payments, or store customer data on a server. The generated online-store cart is a simulation. New generated drafts require review before publication.
